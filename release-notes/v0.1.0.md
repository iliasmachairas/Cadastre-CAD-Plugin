First public version.

**Download:** `Cadastre-Setup.exe` below (under *Assets*).

- Parcels and neighbours with ΚΑΕΚ from data.gov.gr (`KDOMORA`)
- Forest maps: ratified, posted and 1945 (`KDDASIKA`)
- Satellite background that follows the view (`KDMAPON` / `KDMAPOFF`)
- ΕΓΣΑ87 ↔ WGS84 (`KDGRT`), drawing scale (`KDSCALE`), coordinate grid (`KDGRID`)
- English manual (`KDHELP`)

Supported: AutoCAD / Civil 3D 2021–2026, ZWCAD 2026, GstarCAD 2027.

If Windows shows "Windows protected your PC": **More info → Run anyway** (the setup is not yet digitally signed).
