**Download:** `Cadastre-Setup.exe` below (under *Assets*). Installing it over 0.1.0 updates it; close your CAD program first.

- New **Σχετικά** button (`KDABOUT`): about the tool and its author
- **Οδηγίες** (`KDHELP`) now shows the steps in the command line and always opens the manual, in AutoCAD, ZWCAD and
  GstarCAD alike (the manual is now part of the plugin itself)
- A little more space between the Οδηγίες and Σχετικά buttons

Supported: AutoCAD / Civil 3D 2021–2026, ZWCAD 2026, GstarCAD 2027.

If Windows shows "Windows protected your PC": **More info → Run anyway** (the setup is not yet digitally signed).
